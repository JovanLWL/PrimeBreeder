Découvrez les chiens que les utilisateurs de Prime Breeder ont choisi de partager. Recherchez par nom du chien, race ou éleveur, y compris le nom public de l’élevage ou le nom affiché du propriétaire. Ouvrez un pedigree partagé pour voir les ancêtres publiés.

Ce qu’affiche un profil public

Consultez les informations de base comme la race, le sexe et la couleur de robe. La photo, le pedigree, les résultats génétiques, certains résultats de santé et les titres ou résultats d’exposition n’apparaissent que si le propriétaire les partage. Les dossiers privés de l’élevage restent privés.

Choisir les informations à publier

Ouvrez Profil du chien → Visibilité du chien. Par défaut, les chiens sont privés et absents des recherches. Choisissez Public pour publier les champs autorisés. Vous décidez de partager ou non le pedigree, la génétique, la santé et les données d’exposition.

Étudier un accouplement avec votre chien

Ouvrez le profil d’un chien avec un pedigree partagé, choisissez Accouplement hypothétique puis un chien admissible dans Mes chiens. L’analyse affiche le COI, l’AVK, les ancêtres communs et le taux de complétude du pedigree. Les prévisions génétiques exigent des données adaptées. Les résultats dépendent de la profondeur du pedigree, de l’identification des ancêtres et des données publiées. Le calcul laisse intacts les dossiers de reproduction, de gestation et de portée.

Accéder à l’outil

Connectez-vous et ouvrez Base de données canine depuis l’accueil. Vous pouvez l’ajouter comme l’une des neuf tuiles facultatives du tableau de bord. Le lien ouvre l’annuaire et vous y ramène après la connexion.
